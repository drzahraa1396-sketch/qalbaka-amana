# قلبك أمانة — V5

نسخة تشغيلية مطورة لمساعد الطبيب وإدارة دورة الحملة.

## الجديد في V5
- لوحة طبيب تركز على مهام اليوم والمتابعات والإحالات والخطر المرتفع.
- ملخص سريري وتنبيهات عملية قبل اعتماد الزيارة.
- حساب BMI وتقييم خطر WHO Egypt من الجداول المرفوعة (40–74 سنة فقط).
- مساعد قرار للستاتين والمتابعة وفق المعايير المبرمجة من الدليل المرفوع.
- رسالة تثقيف صحي عملية قابلة للنسخ والحفظ.
- ملف مريض يجمع الزيارات.
- متابعة واستدعاء مع حالات اتصال وحضور.
- إحالات مع 3 متابعات وتغذية راجعة.
- بيان شهري مطابق لقالب Excel.
- تصدير كامل للبيانات.
- Google Sheets للتخزين الدائم عند ضبط Secrets.
- حماية اختيارية برمز دخول.

## التشغيل
```bash
pip install -r requirements.txt
streamlit run app.py
```

> التطبيق دعم قرار للطبيب وليس بديلًا عن الحكم السريري أو التشخيص النهائي.
